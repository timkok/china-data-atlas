# China Data Atlas：参考产品研究与 V0.1 决策

研究日期：2026-11-05（America/New_York）。实查 TheMapsDaily 首页、人口分类、婴儿死亡率详情、Methodology；Chrome 实际查看桌面首页与 390×844 手机首页/详情。以下是抽样研究，不代表全站所有指标均经过审计。

## 十项观察与设计决策

| 项目 | 实际观察 | China Data Atlas 决策 |
|---|---|---|
| 1 首页 | 大标题、搜索、分类入口、平台规模、一个指标的四种视图、最近新增、来源说明。桌面白底、黑字与蓝色强调，大留白；自动播放可暂停。 | 采用搜索优先与数据故事入口，但使用独立字体、色彩、布局；不复制品牌或文案。关键图表置于首屏附近，减少空白占用。 |
| 2 分类 | 主题下有子分类；人口分类提供内部搜索、来源过滤、排序与分页。 | V0.1 用人口社会/经济/教育/医疗四类，避免少量数据过度分类。 |
| 3 地图 | 详情有按年地图与缺失图例，地图的无障碍名称提示用户可查完整表格。 | 交互中国地图暂缓：未经核实的边界和着色审核不能替代合规证明。排名与表格承担正式地区探索。 |
| 4 详情 | 按规模、空间、时间、变化、查询组织，页内导航与醒目 CSV。 | 统一指标模板；Summary、排名、趋势、表格、方法各有稳定锚点；元数据与正文共享同一数据层。 |
| 5 趋势 | 全国趋势与地区比较控件，显示时间区间及累计变化。 | 多省比较、不跨缺口连线；口径变化直接标记，缺少可比基期不算同比。 |
| 6 排名/区域 | 最高最低榜、完整排名切换、全国差值、地区中位数。 | 使用公开定义的七大区域；全国值仅用官方值，不能将率/人均指标的省均值当全国值。 |
| 7 CSV/Explorer | 有 CSV 入口与折叠 Explorer；显示行列数、类型、缺失、范围、字段说明。未逐行审计其 CSV。 | CSV 必须直接从图表同源规范化数据生成，保留来源/状态/口径字段，并支持可检验过滤。 |
| 8 来源/方法/引用 | 详情链接官方机构、具体出版物与表号；提供引用；总方法说明保存原始版本、缺口不填补、边界历史。 | 保留原始文件及哈希、来源到记录映射、版本与转换规则；明确质量规则通过项，不用不透明的综合分数。 |
| 9 SEO/发现 | 搜索引擎可读取独立详情 URL、标题、正文、数据表与相关指标。未审计其 sitemap、robots 或全部 metadata。 | 静态预生成正文、独立中文 metadata、sitemap、OG 和相关指标，禁止无数据的批量 SEO 页面。 |
| 10 手机体验 | 390px 下导航折叠、搜索/分类换行，详情标题和下载按钮可读；页内导航为横向区域；首屏需要较多滚动才能见到图表。 | 缩短手机 Hero，触摸控件至少约44px，表格允许内部横向滚动，主页面不溢出。 |

来源：[首页](https://themapsdaily.com/)、[人口分类](https://themapsdaily.com/categories/demographics)、[样本详情](https://themapsdaily.com/posts/in-infant-mortality-rate)、[方法说明](https://themapsdaily.com/methodology)。

## 需要超越的真实问题

样本详情 H1 与首段写全国婴儿死亡率 **27**，同页 Summary/图表则显示 **2023 年 25**。浏览器与页面文本均观察到这一不一致。这不是对该站全部数据质量的结论，但说明“文案与图表数据同源”应成为本项目的自动检查项。页面的因果式解释也不应照搬；本项目只自动生成有计算依据的描述性发现。来源可追溯并不自动保证叙述一致、推论有效或权利许可完整。

## 中国已有官方产品与补位空间

- [国家数据](https://data.stats.gov.cn/) 当前入口跳转至 JS 应用；纯文本抓取只收到启用 JavaScript 的提示。这是本次获取方式的限制，不代表官方站没有数据。应正常使用公开入口，不能绕过验证码或访问限制。
- [中国统计年鉴目录](https://www.stats.gov.cn/sj/ndsj/) 提供按版年组织的出版入口。年鉴版年、统计年度、发布日必须分开记录；选择同一版年数据可减少不同修订版本混用。
- [年度统计公报](https://www.stats.gov.cn/sj/tjgb/ndtjgb/) 是原始发布的重要入口，但叙述式发布与异构表格需要标准化后才能比较。
- 本项目定位为这些原始来源之上的透明再加工层：减少重复清洗，提供统一地区代码、可追溯记录、同源下载和交互比较，不宣称替代官方发布。

## 地图决定及依据

[自然资源部地图技术审查中心标准地图服务](https://bzdt.tianditu.gov.cn/)明确说明标准地图编辑改动、以及自助制图输出在公开使用前需要送审；自助制图功能需注册。本次没有取得针对本平台动态省级着色的许可或审核确认，故 V0.1 **不加载地图边界、不绘制替代轮廓图**。正式上线排名、趋势、地区筛选和数据表。未来引入地图前再核实资源许可、审图号、动态改动范围与适用部署条件。

统计分析覆盖中国大陆31个省级行政区。港澳台未纳入首批指标数据范围是统计覆盖说明，不作为地理归属判断。

## MVP 产品边界

以“找到指标→选省份→核对来源/下载”为主流程，目标三次点击内可查看任意已覆盖省份最新值。首页、四类目录、统一指标详情、年份/省份筛选、排名/趋势/多省比较、CSV、数据字典、质量与方法页是首版范围。只展示实际验证成功的年份；2000 年起的全覆盖不是虚构补齐的理由。跨指标散点、导出图片与 AI 保留后续接口；不启用付费 AI 服务。
