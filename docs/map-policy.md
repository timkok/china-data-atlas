# 地图发布决策
V0.1 暂缓地理边界与省级着色地图，使用排名、趋势和明确列出的统计分组。没有使用未经核验的 GeoJSON，也没有将缺失值表示为地理归属判断。统计范围：中国大陆31省级行政区；香港、澳门、台湾暂不纳入此统计样本。

核验依据（2026-11-05）：
- 地图管理条例：https://www.mee.gov.cn/zcwj/gwywj/202001/t20200114_759322.shtml
- 地图审核管理规定：https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202101/t20210105_146368.html

尚未确认具体底图的使用许可，以及交互着色后的最终表达是否符合豁免条件或需要重新审核。以上为产品发布限制，不作法律合规认证。后续上线前需记录底图来源、许可、审图号、最终表达及适用审核结论。
