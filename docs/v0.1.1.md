# V0.1.1 使用体验更新

- 分享视图保留年份、省份组合、排名/趋势/表格、区域、搜索、排序、趋势起止年和全部年度开关；重新打开可还原。无效参数自动采用有效默认值。
- 首页省份链接直接进入该省趋势，解决链接参数与当前视图不一致的问题。
- 趋势起止年可选，保留真实年度观测，不做插值。
- SVG下载包含图表、单位、年份、来源和口径说明。
- 数据表可查看全部年度，与地区/搜索筛选和CSV导出同步；增加记录数和固定表头。
- 引用只列当前统计年度对应的来源，避免把跨版资料混入单年度引用。
- 手机控件与省份选择增加点击区域；详情组件整理为可维护格式。
