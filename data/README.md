# 官方数据及复现

`atlas.json` 为网站唯一数据层。当前10指标、1,308条观察值，31省级行政区（不含港澳台统计覆盖）及有明确官方值的全国序列。

- 人口、城镇化：2015–2024；收入：2018–2024。
- GDP、人均GDP、出生率、本专科在校生、高校数量、医师密度、床位总数：2023–2024。
- 来源：《中国统计年鉴2024》《中国统计年鉴2025》国家统计局公开原始表格图片，保存于`raw/`。`atlas.sources`含官方URL、表名、获取日期、SHA256。
- 获取日期按任务所在地记录2026-11-05；未获取精确发布日期，明确null。
- GDP和人均GDP按表脚注标初步；其他指标没有逐值修订状态说明，标未知，不把出版事实等同正式/终值。

## 处理流程

1. 下载工具依赖 `requests`（`python3 -m pip install requests`）；`python3 scripts/fetch_sources.py` 下载公开原表到新的work/source-staging时间目录并校验快照指纹；拒绝访问即记录错误，不绕过控制。
2. 人工审核导入：复制审核模板到新的reviewed文件，指定year、固定regions顺序、source和32项values（全国+31省）。缺失用null，绝不填0。至少由另一审核者对照原图复核列标题、单位、年份、行序、数值。保留旧快照及文件，不自动覆盖。
3. `python3 scripts/build_data.py` 验证行数、地区顺序、唯一键并生成atlas；直接转录原值，没有缩放、插值或平滑。2023/2024截面540个值和其余768个历史值均已由两个独立AI代理对照原图转录、复核，历史768格逐值比较零差异。详见audit/audit-history-result.json。未经过人类统计专家签署。OCR探索识别错误较多，未用于自动发布。
4. `python3 scripts/validate_data.py` 执行质量门；网站、CSV和图表只消费同一数据层。
5. PR人工审阅后再发布。自动更新仅下载候选快照，不能替换已审核数据。

## 口径与可比性

GDP为现价、初步数据，2023来自2024版、2024来自2025版，经济普查修订可能影响可比基数。禁止自动计算或宣称实际同比增长，图中应提示断点/版本差异。国家GDP不能由省份相加代替。省级人口未含现役军人，全国包含，不能强制两者相等。全国比重和人均值不可由省份简单平均。

教育在校生明确为普通、职业本专科，不包含研究生。学校数单位所，不能沿用表页一般单位“人”。床位总数直接使用万张；未把年末人口作为未经确认的分母计算每千床位。65岁及以上占比暂缓，因为年鉴相应表为抽样调查样本年龄结构，未取得可与全人口估计直接等同的省级口径；社会消费品零售总额暂缓，尚未完成31省原表与版本核验。

行政代码采用六位省级代码，当前历史2015年后31省级区域稳定；不处理省内市县边界，也不将无数据解释为地理归属。全国代码000000为平台汇总标识，不是省级行政代码。

## 访问限制记录

国家数据旧版easyquery公开接口在本次环境返回403（UrlACL），已停止该路线，未绕过访问控制。改用国家统计局公开年鉴原始JPG表。2025版年鉴代表2024统计年度，不代表已覆盖2025或2026年数据。后续版本需按新的官方发布再次核验。
